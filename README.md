# Online Bookstore Sales Analysis using PostgreSQL

## Project Overview

This project analyzes an online bookstore database using PostgreSQL.
The database contains information about books, customers, and orders.

The objective of the project is to use SQL to answer business questions
related to sales, customers, books, revenue, and inventory.

## Database Schema

The database consists of three tables:

- Books
- Customers
- Orders

## SQL Concepts Used

- SELECT and WHERE
- ORDER BY
- GROUP BY
- HAVING
- Aggregate Functions
- JOINs
- Subqueries
- CTEs
- Window Functions
- CASE statements
- COALESCE

## Business Questions

### Basic Analysis

1. Retrieve all books in the Fiction genre.
2. Find books published after 1950.
3. List customers from Canada.
4. Show orders placed in November 2023.
5. Calculate total stock available.
6. Find the most expensive book.
7. Find customers who ordered more than one quantity.
8. Find orders where total amount exceeds $20.
9. List all available genres.
10. Find the book with the lowest stock.
11. Calculate total revenue.

### Advanced Analysis

1. Calculate total books sold for each genre.
2. Find the average price of Fantasy books.
3. Identify customers who placed at least two orders.
4. Find the most frequently ordered book.
5. Find the top 3 most expensive Fantasy books.
6. Calculate total quantity sold by each author.
7. Identify cities where customers spent over $30.
8. Find the customer who spent the most.
9. Calculate remaining stock after fulfilling orders.

### Advanced SQL

#### Subquery
Find books priced higher than the average book price.

#### CTE
Identify the top 5 customers based on total spending.

#### Window Function
Rank books based on total quantity sold.

## Key Insights

- Identified the highest-selling genres and authors.
- Identified the highest-spending customers.
- Analyzed book pricing and inventory levels.
- Calculated total revenue generated from orders.
- Identified frequently ordered and best-selling books.
